# Saeed Learning / Teach Mode

Learned skills are data-only JSON files under %APPDATA%\Saeed\skills\.

A skill contains trigger phrases and an ordered list of existing Saeed tool calls. The runner never evaluates JavaScript and never executes arbitrary code. Every step is routed through the normal ToolRegistry, so permissions and confirmation policies still apply.

Example:
{"id":"open-gmail","name":"Open Gmail","version":1,"trigger":{"phrases":["افتح جيميل","open gmail"]},"steps":[{"tool":"open_url","args":{"url":"https://mail.google.com"}}]}

The same format can later be generated by a visual recorder without changing the runner.
